# 公共层 · 本机约定（安装器铺出的骨架）

> 这份文件由 `skill/install.py` 铺出，只有骨架。**装完请把本机事实补进最后一节**——
> 它是 `bin/装交接.py` 判断「这个目录是不是公共层」的标记之一，别删。

## 这是什么

`公共层/` 不是打包单位，只提供四样东西：

| 路径 | 作用 |
|---|---|
| `bin/装交接.py` | 给项目铺/刷交接；`--scan` 盘点桌面谁缺，`--apply` 一次补齐 |
| `bin/打包引导包.py` | 产出「引导包」：规则 + 标准脚本，给新机器/新项目装规则用 |
| `bin/模板/` | 标准脚本母版（`打包进度.py`、`接手进度.py`），所有项目副本与它同 sha256 |
| `工作流-双机交接规则.md` | 规则唯一权威版本（首行 `改版 vX.Y`，接手脚本按它归一化） |
| `plugins/dsh-autohandoff/` | 自动铺交接的 DSH 插件源码（安装走 DSH 的 `plugin_manager`） |

`_日志/`（插件审计）、`_历史/`（归档）、`引导包/`（产出）、`素材库/`、`工具/` 空着也正常。

## 交接怎么用

每个项目是**桌面的直接子目录**，各自带 `bin/打包进度.py`、`bin/接手进度.py`、`收件箱/`、`发件箱/`：

- 离开前（在要离开的项目里）：`python bin/打包进度.py --lite`
- 到另一台（在对应项目里）：`python bin/接手进度.py 收件箱/<包>.zip`
- 只看不写：`--list` / `--dry-run`

包只含本项目（`MANIFEST.scope` = 项目目录名），接手四道关：scope → 签名 → 逐文件 sha256 → 合并解压。
完整规则见 `工作流-双机交接规则.md`；踩过的坑见 skill 的 `references/坑与教训.md`。
