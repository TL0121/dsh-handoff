# 迁移检查清单（新机器 / 新项目）

> 顺序是硬要求：**先铺层 → 项目就位 → 补交接 → 装插件 → 验证 → 最后才打包**。
> 结构没稳定就打的包会缺脚本、旧规则，对方接手后必须返工。
> 每步都写了 x86（Windows）与 mac 两种命令，照自己平台挑一行。

## 0. 前置

```bash
# 平台 / 解释器 / 平台件（同一件东西两机必须同大版本）
uname -s; python3 -V; ls /Applications/<App>.app/Contents/MacOS/<bin>   # mac：确认无头程序的绝对路径
ver; python -V; dir "C:\Program Files\<厂商目录>"                        # win
```

- 脚本只用 Python 标准库（3.9+ 即可）；**不要**用 `python3` 在 Windows（商店占位符，退出码 9009）。
- 平台件（渲染/建模/视频等专用程序）各机自备，**不进包**；同一件东西两机必须同大版本。

## 1. 铺公共层（只写公共层，不碰项目）

```bash
# 一条命令（在 skill 目录里；Windows 把 python3 换成 python）
python3 install.py                                     # 先看（dry-run，默认）
python3 install.py --apply --smoke                     # 真写 + 临时项目自测 8 项
python3 install.py --desktop ~/Desktop --apply         # 桌面被重定向时显式指定
python3 install.py --apply --force-agents              # 连 AGENTS.md 一起覆盖
```

装完的结构：

```
公共层/
├── 工作流-双机交接规则.md      ← references/交接规则.md
├── AGENTS.md                  ← 本机约定骨架（已有则保留；装完把本机事实补进最后一节）
├── bin/装交接.py  bin/打包引导包.py
├── bin/模板/打包进度.py  接手进度.py
├── plugins/dsh-autohandoff/   ← assets/plugin/dsh-autohandoff
└── _日志/ _历史/ 引导包/ 素材库/ 工具/
```

没装 python 或想纯手工时，把上表逐项拷过去即可（规则在 `references/`、脚本在 `assets/scripts/`、
插件在 `assets/plugin/`、AGENTS 骨架在 `assets/layer/AGENTS.md`）。

> `AGENTS.md` 是**本机约定**：安装器默认保留已存在的那份（各机路径不同），要覆盖加 `--force-agents`。
> 它同时是 `装交接.py --scan` 判断「这里是不是公共层」的标记之一，别删。

## 2. 项目就位（只移动，不删除）

**标准形态**：项目是桌面的直接子目录（`~/Desktop/<项目>/`），与 `公共层/` 同级。
判据：目录里有 `bin/打包进度.py` 就是工作区根。

```bash
# 先盘点（macOS/Linux；Windows 用 PowerShell 的 Get-ChildItem 数文件即可）
for d in */; do printf "%s\t%s\t%s\n" "$d" "$(find "$d" -type f | wc -l)" "$(du -sk "$d" | cut -f1)"; done

# 搬（移动，不是复制；别用 cp -R）
# macOS / Linux：~ 不要加引号，加了就不展开
mv ~/Desktop/旧工作区/项目名 ~/Desktop/
# Windows（PowerShell）
Move-Item "$HOME\Desktop\旧工作区\项目名" "$HOME\Desktop\"
```

- 搬完**立刻核对**文件数与字节数，必须一致。
- `.dsh/`、`收件箱/`、`发件箱/`（含 `.已接手.json`）跟着搬，别删别清空。
- 改名（如 `旧项目名` → `新项目名`）要同时清掉项目内写死的旧路径；改完 `grep -r 旧名` 残留 0。

## 3. 补交接

```bash
python3 公共层/bin/装交接.py --scan --desktop ~/Desktop            # 看谁缺（只列）
python3 公共层/bin/装交接.py --scan --desktop ~/Desktop --apply    # 补齐
python3 公共层/bin/装交接.py ~/Desktop/新项目 --append-agents --init-agents   # 单个
```

- 不想被铺的目录：放一个空 `.no-handoff`。
- 每个项目会得到 `bin/` 两个脚本、`收件箱/README.md`、`发件箱/README.md`、`AGENTS.md` 两节（已有就跳过）。

## 4. 装插件（DSH 内操作）

1. `plugin_manager` → `install_bundle`，`target` 用**绝对路径** `公共层/plugins/dsh-autohandoff`。
2. `enabled: true`；`application: restart-required` → 重启 DSH。
3. 「设置 → 插件」应出现「新项目自动铺交接」。
4. 冒烟：新建空目录 → 在里面开会话 → 出现 `bin/`、收发箱、AGENTS 两节；日志在 `公共层/_日志/自动交接.log`。

## 5. 验证（全绿才打包）

```bash
# 每个项目只看不写
cd 项目 && python bin/打包进度.py --list      # 期望 scope=项目名，文件数量级正确
# 汇总
python 公共层/bin/装交接.py --scan --desktop ~/Desktop   # 应"所有一级目录都已有交接脚本"
# 版本对齐（所有项目应与母版同 sha256）
sha256sum 公共层/工作流-双机交接规则.md 项目/工作流-双机交接规则.md
```

## 6. 首次收发

```bash
# 收：包放进 该项目/收件箱/ → 先 dry-run
python bin/接手进度.py 收件箱/<包>.zip --dry-run
python bin/接手进度.py 收件箱/<包>.zip          # 按母版归一化规则；发件箱默认保留
# 归一化（包里的脚本可能是旧的）
python 公共层/bin/装交接.py 项目                 # 显式传项目名；--scan --apply 无效
cp 公共层/工作流-双机交接规则.md 项目/
# 发：离开前
python bin/打包进度.py --list && python bin/打包进度.py --lite
```

## 7. 汇报模板

```
[平台] mac/win + python 版本 + 平台件版本
[结构] 桌面路径；迁移：旧→新（文件数/字节 前/后）
[公共层] 文件数；规则版本 vX.Y
[插件] install_bundle 结果；冒烟 PASS/FAIL
[验证] 各项目 --list 的 scope 与文件数
[包] 名称 / 大小 / 条目数
[异常] 无 / 具体现象
```

## 常见失败对照

| 现象 | 处置 |
|---|---|
| `--scan` 把所有已有项目都列出来 | 检测键失效（脚本过旧）；升级脚本后再跑 |
| 接手报 `scope 不一致` | 目录名与包内 `scope` 不同（改名后常见）；改用正确目录，别 `--force` |
| 接手报 `已经接过` | `.已接手.json` 有记录；确认要重接才 `--force` |
| 包内少文件 | 权限锁死目录被静默跳过；`--list` 对数量、修权限 |
| 新项目不自动铺 | 插件未装/未重启 / 不在桌面一级 / 无 `python` / 有 `.no-handoff` |
| 输出方块 | 用了旧版脚本（非终端未强制 UTF-8）；升级脚本 |
